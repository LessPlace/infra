Сначала выполнить [список для консоли](CONSOLE-CHECKLIST.md). Исследование защиты:
[стоимость и ограничения WAF](WAF-COST.md).

`publish-web.py` публикует уже собранный образ. `deploy-web.py` — начальная установка,
требует переменную `LESS_PREVIEW_PASSWORD`; после установки Backoffice его не использовать:
он рассчитан на первоначальный edge без административной сети. Текущий edge обновляется
командами с двумя Compose-файлами из инструкции Backoffice. Это не завершённый механизм обновления с откатом.
Перед последующим обновлением сохранить digest действующей и предыдущей версии. Удалять старые
выпуски только после проверки нового; не удалять дочерние манифесты активного OCI-образа.

`deliver-secrets.py` запускается root на ВМ перед развёртыванием, получает только пять
разрешённых секретов и атомарно заменяет локальные файлы. Это не автоматическая ротация:
смена пароля в Lockbox требует отдельного согласованного обновления БД/ACL и контейнеров.
`initialize-databases.py` создаёт только отсутствующие роли и БД; не меняет пароли существующих
ролей и не сбрасывает данные. Наполнение CP выполнено вручную из `manual-control-plane.sql`.
`publish-service.py` публикует локальную сборку; `registry-pull.py` загружает выбранный сервис
от имени ВМ. Временные Docker-реквизиты удаляются после операции.

## Исправление возврата OAuth — 05.10.2026

Причина подтверждена владельцем: Яндекс возвращает `state`, `code`, `cid`; VK возвращает
`code`, `expires_in`, `device_id`, `state`, `ext_id`, `type=code_v2`. Старый разбор отвергал
`cid` и принимал успешный VK только как JSON `payload`, выдавая `oauth_state_invalid`.
