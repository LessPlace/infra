# Accounts: очередь одобрения регистраций

Для подключения Accounts к промышленному Backoffice нужен отдельный Lockbox-секрет
`less-prod-backoffice-accounts`, защита удаления включена. Поля:

- `DB_PASSWORD`: новое значение `openssl rand -hex 32` для отдельной служебной роли Accounts;
- `BACKOFFICE_PROXY_SECRET`: другое новое значение `openssl rand -hex 32`.

Назначить `lockbox.payloadViewer` сервисному аккаунту `service` (`ajefiauik875043qbf7r`)
на самом секрете. Значения не присылать. Права на каталог, новая ВМ, бакеты и внешние
сетевые правила не нужны: соединение полностью внутри common-ВМ.

Отдельный серверный сертификат `accounts.backoffice.internal` будет подписан существующим
машинным УЦ владельцем. Команда выпуска будет добавлена после подготовки открытого CSR.
Закрытый ключ создаётся и остаётся на common-ВМ.
